# Russian Study

Простое приложение для изучения русского с французского: карточки с интервальным повторением, словарь и озвучка. Ничего лишнего — без уроков, уровней и аудирования.

- **Révision** — карточки без дневного лимита. Направление (FR → RU, RU → FR, оба) выбирается прямо на странице. Оценки: *À revoir / Difficile / Bien / Facile*, клавиши `Пробел`, `1–4`, `R`. Сверху — план повторения (сегодня / завтра / 2–15 дн / позже, среднее время и изменение за день и неделю); клик открывает подробную динамику: графики плана, средний срок, новые слова, ответы, прогноз на 14 дней.
- **Statistiques** — карточки, к повторению, выученные, процент успеха, серия дней, последние ответы.
- **Vocabulaire** — весь словарь (при первом запуске добавляется стартовый набор: 50 базовых слов и 10 фраз из `web/starter.json`, дальше слова добавляются вручную и удаляются свободно; большой набор из 735 слов лежит в `extras/starter-vocabulary.json`), поиск, озвучка каждой записи, добавление и удаление слов.
- **Карточка** — кнопка «Modifier» (✎) в углу открывает правку слова (французский и русский); прогресс слова сохраняется.
- **Réglages** — язык интерфейса (FR / EN), голос (Svetlana / Dmitry), скорость, автозвук, сброс прогресса.

## Озвучка: хороший голос или по умолчанию

Хороший голос это нейросетевой (Svetlana/Dmitry) с локального сервера. Всё остальное (голос системы/браузера) считается «по умолчанию» и **всегда** отмечается жёлтой полосой вверху страницы с кнопкой «Détails»: какой голос запрошен, какой реально играет, причина (нет интернета / сервис отказал 403 / нет edge-tts / локальный сервер не отвечает / таймаут) и что делать, плюс технический текст ошибки. Кнопка «Revérifier» перепроверяет без прослушивания; проверка идёт и при запуске. В «Réglages» режим **«Uniquement la bonne voix»** полностью запрещает голос по умолчанию (без нейросетевого голоса ничего не читается). Работает одинаково в exe.

## Как устроено запоминание

Тот же алгоритм, что в исходном приложении: **FSRS** (`ts-fsrs`, целевое удержание 90%, шаги обучения 1 мин / 10 мин, лицензия MIT в `web/vendor/ts-fsrs/`). Очередь строится заново после каждого ответа: сначала карточки в обучении, затем просроченные по давности, затем новые. Кнопки показывают реальные интервалы («1 мин / 6 мин / 10 мин / 8 дн»). Старые расписания из прежней версии (SM-2) при загрузке автоматически конвертируются.

## Запуск

**macOS:** двойной клик по `Russian Study.command`.

**Windows:** двойной клик по `start-windows.bat` (нужен Python 3.9+ с python.org; скрипт сам создаст окружение, поставит `edge-tts` и откроет браузер). Порт по умолчанию 5174, другой — `start-windows.bat 5175`.

**Один файл `RussianStudy.exe` (Windows 10/11, Python не нужен):** собирается на GitHub, локально Windows не требуется. На GitHub: *Actions → Build Windows exe → Run workflow*, через пару минут скачайте артефакт `RussianStudy-windows` (внутри `RussianStudy.exe`). Либо создайте тег `v1.0`, и exe появится в *Releases*. Положите exe в отдельную папку: рядом с ним создаются `user-data/` (прогресс и копии) и `.tts-cache/`. Двойной клик открывает браузер; закрытие чёрного окна останавливает приложение. При первом запуске Windows SmartScreen покажет предупреждение (exe без платной подписи): «Подробнее» → «Выполнить в любом случае».

Вручную:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py        # http://localhost:5174
```

Прогресс хранится в `user-data/russian-study.json` (не в git). Три места хранения: (1) `user-data/russian-study.json` рядом с приложением, (2) копия в стандартной папке пользователя (Windows `%APPDATA%\RussianStudy`, macOS `~/Library/Application Support/RussianStudy`), (3) читаемый список слов `my-words.txt` рядом с приложением (формат `французский ; русский`, его можно вставить в «Plusieurs mots»). Если основного файла нет (например, exe перенесли в новую папку), прогресс восстанавливается из копии (2). Защита данных: атомарная запись с `fsync`; перед каждой записью предыдущая версия сохраняется как `russian-study.backup.json`, плюс по копии в день в `user-data/backups/` (последние 7); счётчик ревизий не даёт старому окну затереть новые данные (будет сообщение «Reload»); при ошибке чтения ничего не пишется, а повреждённый файл восстанавливается из копии. Озвучка — нейросетевой голос Microsoft Edge (`edge-tts`, нужен интернет при первом прослушивании слова; дальше берётся из `.tts-cache`). Без интернета используется голос браузера.
